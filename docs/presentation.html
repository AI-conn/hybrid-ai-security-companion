The Problem

Security researchers leak data
every time they paste into cloud AI

What goes up

Raw bug reports, vulnerability details, PII, internal IP addresses, exploit routes — all sent to a third-party model for inference.

What comes back

A summary, an attack scenario, a severity rating — and your data living on someone else's servers, logged, retained, and out of your control.

That's not a workflow. That's a liability.

The Toolkit

Four tools. One menu.
Built for a bounty chain.

Summarize

Raw bug report → vulnerability class, affected component, attack route, severity call.

Attack Scenario

Vulnerability → Google VRP format: who the attacker is, what they gain, how they carry it out.

Redact

Security text → emails, contact numbers, and names replaced before hitting a public tracker.

Severity

Finding → Critical / High / Medium / Low / Info with a one-line justification.
