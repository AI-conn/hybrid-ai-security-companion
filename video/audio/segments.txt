01-hook|Security researchers handle sensitive data. What if your AI could do it without sending anything to the cloud? This extension runs Gemini Nano 4 entirely on-device — and only reaches for the cloud when it has to.
02-device|Here it is on a real vulnerability finding. Load it in, hit Summarize. Watch the badge: ON-DEVICE, Gemini Nano 4. That inference ran inside Chrome — nothing left this machine. The result comes back in seconds: the vulnerability class, the affected element, the attack trail, and a severity call. Structured results, zero serving cost, zero data leaving the box. That's the confidential default — the model lives on your machine.
03-hybrid|Now the twist that makes this hybrid. Same menu — but this time I'm loading in a full advisory, far beyond what a small on-device model can hold. The engine sees Nano can't take it, and routes the identical request to Gemini in the cloud through Firebase AI Logic. The result is tagged CLOUD. Same call, same interface — on-device when feasible, cloud when needed.
04-tools|The other three tools run through the same engine. Attack Scenario writes the attack route in Google's reward format — who the attacker is, what they gain, how they carry it out. Redact scrubs emails, contact numbers, and names before a finding goes to a shared tracker. Severity rates the finding Critical to Info with a one-line justification. Four workflows, one menu, built for a bounty chain.
05-arch|Here's the architecture. The menu makes one call into the Firebase AI Logic SDK. The engine asks two questions: is Gemini Nano available on this machine, and does the text fit its context window? If both are yes, inference runs locally — confidential, free, offline. If either is no, the same call goes to Gemini in the cloud through Firebase. One interface, two runtimes, the tool doesn't care which one answered.
06-cta|Full source is on GitHub under a free software license. Getting started takes three commands: clone, install the libraries, load the dist folder into Chrome. If you hunt bugs, this gives you a confidential AI layer for your workflow — free when it's local, strong when it's cloud, and never sending your data anywhere it doesn't have to go.
